# FinSync Intelligence collaboration guide

This is a three-hour hackathon build. Keep the application runnable after every phase and preserve the shared API contracts. Do not rename shared fields without coordinating frontend and backend; both developers may edit shared types only after verifying both sides.

- Never fabricate citations or guarantee financial outcomes.
- Missing source material must reduce confidence; without verified evidence, return `insufficient_data`.
- Simulated data must remain visibly labeled.
- Developer 1 owns backend agents, retrieval, synthesis, orchestration, and metrics.
- Developer 2 owns frontend, profile UX, portfolio/watchlist UI, and visualization.
